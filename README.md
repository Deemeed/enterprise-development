# Carwash

Лабораторная работа № 2

Реализовано серверное приложение с использованием REST API, которое осуществляет базовые 
CRUD-операции с реализованными в Лабораторной № 1 сущностями и предоставляет результаты аналитических 
запросов к данным.

Хранение данных осуществляется в памяти в виде коллекций.

## Структура проекта

`Carwash.Domain` - проект с классами предметной области.
`Carwash.Application` - проект с бизнес-логикой и сервисами.
`Carwash.Tests` - проект с unit-тестами.
`Carwash.API` - проект с REST API контроллерами.
`Carwash.Application.Contracts` - проект с Dto и интерфейсами контрактов.
`Carwash.Infrastructure.InMemory` - проект с реализацией инфраструктуры inmemory.
`Carwash.Shared` - проект с общим классом с перечисленными enum-ами.

## Функциональные возможности

CRUD-операции для сущностей:
- Клиент
- Автомобиль
- Заказ
- Услуга

Аналитические запросы:
- Получение топ-5 клиентов по количеству посещений.
- Получение автомобилей, находящихся на мойке в данный момент.
- Получение топ-5 наиболее популярных услуг.
- Определение для выбранного бокса мойки времени, с которого он освобождается.
- Определение суммарной выручки по каждой услуге.

### Тесты

#### GetTopFiveClients_ShouldReturnClientsOrderedByVisitCount

Находит топ-5 клиентов по количеству посещений.

Используются группировка и подсчёт заказов.

#### GetCarsCurrentlyAtCarWash_ShouldReturnActiveOrders

Находит автомобили, находящиеся на мойке в данный момент.

Проверяется попадание текущего времени в интервал обслуживания заказа.

#### GetTopFivePopularServices_ShouldReturnServicesOrderedByOrderCount

Находит топ-5 наиболее популярных услуг.

Используется группировка по услуге и подсчёт количества заказов.

#### GetBoxFreeTimeForSelectedBox_ShouldReturnCorrectFreeTime

Определяет для выбранного бокса мойки время, с которого он освобождается.

Результат вычисляется как момент окончания последнего заказа в боксе.

#### GetTotalRevenueByService_ShouldReturnCorrectRevenue

Определяет суммарную выручку по каждой услуге.

Сумма рассчитывается по стоимости услуги и количеству заказов на неё.
