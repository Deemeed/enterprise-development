# CarWash

Лабораторная работа № 1

Реализовать объектную модель предметной области автомойки и набор unit-тестов с использованием LINQ.

Данные хранятся в памяти в виде коллекций.

## Структура проекта

### CarWash.Domain

Основной проект с классами предметной области.

#### Entities

- `Client` — клиент автомойки.
- `Car` — автомобиль, принадлежащий клиенту.
- `Service` — услуга автомойки и её стоимость.
- `Order` — заказ на обслуживание автомобиля.

#### Enums

- `Category` — категория автомобиля.

Возможные категории:
- `Standard`
- `Premium`
- `Luxury`
- `Suv`
- `Minivan`

#### Data

- `DataSeed` — тестовые данные проекта.

Содержит:
- 7 клиентов;
- 8 автомобилей;
- 5 услуг;
- 26 заказов.

---

## CarWash.Tests

Проект с unit-тестами.

### QueriesTestsFixture

Тестовая фикстура.

Подготавливает данные из `DataSeed` для тестов.

### QueriesTests

Класс с тестами с LINQ-запросами и проверками результатов.

### Тесты

#### GetTopFiveClients_ShouldReturnClientsOrderedByVisitCount

Находит топ-5 клиентов по количеству посещений.

Используются группировка и подсчёт заказов.

#### GetCarsCurrentlyAtCarWash_ShouldReturnActiveOrders

Находит автомобили, находящиеся на мойке в данный момент.

Проверяется попадание текущего времени в интервал обслуживания заказа.

#### GetTopFivePopularServices_ShouldReturnServicesOrderedByOrderCount

Находит топ-5 наиболее популярных услуг.

Используется группировка по услуге и подсчёт количества заказов.

#### GetBoxFreeTimeForSelectedBox_ShouldReturnCorrectFreeTime

Определяет для выбранного бокса мойки время, с которого он освобождается.

Результат вычисляется как момент окончания последнего заказа в боксе.

#### GetTotalRevenueByService_ShouldReturnCorrectRevenue

Определяет суммарную выручку по каждой услуге.

Сумма рассчитывается по стоимости услуги и количеству заказов на неё.
